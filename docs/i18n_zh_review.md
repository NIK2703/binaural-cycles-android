## 1. Функциональные пробелы (не качество текста, но влияет на пользователя)

### 1.1 Нет перевода для традиционного китайского — подхватывается русский
`values/strings.xml` — это **русский** (default). Китайский лежит только в `values-zh-rCN`.
Устройства с `zh-TW`, `zh-HK`, `zh-MO` не попадают в `zh-rCN` и откатываются на default →
пользователь видит **русский интерфейс**.

Варианты (по возрастанию качества):
1. Дублировать как `values-zh` (упрощённый) — минимум, но лучше русского.
2. Сделать `values-zh-rTW` с конвертацией в традиционный (перевод терминов: 采样率 → 取樣率,
   归一化 → 正規化, 耳机 → 耳機, 后台 → 後台/背景, 缓冲区 → 緩衝區, 双耳节拍 → 雙耳節拍).

### 1.2 Пустая папка `app/src/main/res/values-es`
Пуста, строк нет. Мусор — удалить, либо добавить испанский перевод.

### 1.3 Нет store-метаданных для китайского
`fastlane/metadata/android/` содержит только `en-US` и `ru-RU`. Для публикации в китайских
сторах/витринах нужен `zh-CN` (название, краткое и полное описание, changelogs).

### 1.4 Хардкод русского текста в UI (только debug-панель)
`app/src/main/java/com/binauralcycles/ui/components/DebugTimeControlPanel.kt`:
`"DEBUG: виртуальное время"`, `"Текущее время: …"`, `"Ускорение: …x"`.
Видно только в debug-сборке — можно оставить, но при желании вынести в ресурсы.

## 2. Терминология — главная претензия

### 2.1 «均衡» = эквалайзер, а не нормализация (средний приоритет)
В китайском аудиоконтексте **均衡 / 均衡器 — этоEQ (equalizer)**. В затронутых строках
речь идёт о выравнивании громкости, поэтому «均衡音量» читается как «отэквалайзить громкость».
Кроме того, получилось внутреннее противоречие: заголовок — «归一化», описания — «均衡».

| key | сейчас | рекомендуется |
|---|---|---|
| `volume_normalization_description` | 均衡音量，使听感保持一致 | 平衡音量，使听感保持一致 |
| `normalization_none_description` | 不均衡音量 | 不调整音量（保持原样） |
| `normalization_channel_description` | 根据左右声道音调频率之比均衡音量 | 根据左右声道音调频率之比平衡音量 |
| `normalization_temporal_description` | 按正在播放预设的最低声道频率均衡声道音量 | 按正在播放预设的最低声道频率平衡声道音量 |
| `temporal_normalization_description` | 均衡图表各点之间的音量，使听感保持一致 | 平衡图表各点之间的音量，使听感保持一致 |

Если «归一化» кажется слишком математическим — заменить везде на **音量标准化**
(но тогда менять и `volume_normalization`, и `normalization_strength`, чтобы не разъезжалось).

### 2.2 «淡出时长» для кроссфейда
Fade в `smooth_fade` / `fade_duration` / `step_fade_duration` — это затухание **и** возврат,
а «淡出» означает только fade-out.

| key | сейчас | рекомендуется |
|---|---|---|
| `step_fade_duration`, `fade_duration` | 淡出时长 | 渐变时长（или 淡入淡出时长） |
| `smooth_fade` | 平滑淡出 | 平滑渐变 |
| `smooth_fade_description` | 声道交换时平滑过渡 | ✓ ок, оставить |

Примечание: `step_fade_duration` и `fade_duration` в источнике — два разных ключа
с одинаковым текстом, в zh тоже совпадают — это ок, не баг.

### 2.3 «功耗设置» — несуществующий экран
`battery_optimization_settings_unavailable` = «无法打开功耗设置».
На Android нет раздела «功耗设置»; открывается **电池 / 省电优化**.
→ **无法打开电池设置** (или «无法打开电池优化设置»).

### 2.4 «载波音调频率» — тавтология
`carrier_tone_frequency` = «载波音调频率» (carrier tone frequency).
«音调频率» избыточно; по-китайски говорят «载波频率» или «载波音频率».
→ **载波频率**

## 3. Стилистика и точность (низкий приоритет)

| key | сейчас | проблема | рекомендуется |
|---|---|---|---|
| `update_interval_description` | 播放频率的重新计算频率 | «频率» дважды подряд, тяжело читается | 重新计算播放频率的间隔 |
| `normalization_temporal` | 时间 | как вариант переключателя звучит обрубком | 时间（按整段） / 基于时间 |
| `resume_on_headset_connect` | 连接时恢复 | непонятно — подключение чего? | 连接耳机时恢复 |

| `min_channel_frequency` | 最低声道频率 | читается как «частота самого низкого канала» | 声道最低频率 (аналогично `max_channel_frequency` → 声道最高频率) |

### 3.1 Названия пресетов и приложения

| key | сейчас | комментарий |
|---|---|---|
| `app_name` / `preset_list_title` | 双耳节拍周期 | «周期» в бытовом китайском = менструальный цикл. В сочетании «双耳节拍周期» двусмысленность почти снята, но **双耳节拍循环** или просто **双耳节拍** безопаснее |
| `preset_gamma_productivity` | 伽马高效 | обрублено; лучше **伽马波高效** или **伽马专注** |
| `preset_daily_cycle` | 每日周期 | «ежедневный цикл»; естественнее **全天周期** / **昼夜周期** |
| `preset_circadian_rhythm` | 昼夜节律 | ✓ отлично |

### 3.2 Совпадения, которые НЕ являются ошибками
`hz`, `hz_format`, `hz_value_format`, `hz_value_format_decimal`, `quality_very_low`,
`reduction_percent_format` в zh совпадают с en — это единицы измерения и форматы, так и надо.
`seconds_short` (秒) и `seconds_full` (秒) совпали — в китайском нет краткой формы, нормально.

## 4. Что сделано хорошо

- Единообразно: 预设 (preset), 声道 (channel), 载波 (carrier), 节拍 (beat), 归一化 (normalization),
  放松时段 (relaxation periods), 采样率 (sample rate), 波表合成 (wavetable synthesis).
- Длинные описания (`battery_optimization_prompt_message`, `buffer_generation_description`,
  `swap_mode_trend_description`, `relaxation_range_fade_description`) переведены точно и
  читаются как родной текст, а не калька.
- Справка по жестам (блок `gesture_*`) — лучшая часть файла: естественная разговорная форма
  с 「可」 («можно…»), без канцелярита.
- Учтены locale-нюансы: полноширинная пунктуация, типографские кавычки, пробел между
  числом и единицей (`8 kHz — 最省电`, `%d 分钟`, `%1$d 个采样点`).
